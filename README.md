## 🚀 About

A premium, dark-themed personal portfolio website featuring **3D animations**, **parallax effects**, and a **cinematic intro sequence**. Built to showcase my projects, skills, certifications, and achievements as a B.Tech CSE (AI & ML) student at Lovely Professional University.

> **Live Demo** — https://amit-singh-2006.github.io/Portfolio/

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎬 **Cinematic Intro** | Boot-up animation with progress bar, text sequencing, and slide-away transition |
| 🎴 **3D Tilt Cards** | Interactive mouse-tracking cards with perspective transforms |
| 🌌 **Parallax Orbs** | Floating gradient orbs that follow the cursor |
| 🧊 **Rotating 3D Cube** | CSS-only spinning cube with AI/ML labels in the hero section |
| 📱 **Fully Responsive** | Mobile-first design with collapsible nav and adaptive layouts |
| 🧭 **Scroll Spy Navbar** | Active section highlighting with animated underline indicators |
| 📄 **Resume Download** | One-click CV download & in-browser PDF viewer |
| 💎 **Glassmorphism UI** | Frosted glass cards with backdrop blur and subtle borders |

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/Amit-Singh-2006/portfolio.git

# Navigate to the project
cd portfolio

# Open in browser (no build step required)
# Option 1: Simply open index.html
start index.html

# Option 2: Use a local server (recommended for best experience)
npx -y serve .
```

> **Note:** A local server is recommended to avoid CORS issues with font loading and ensure all features work correctly.
